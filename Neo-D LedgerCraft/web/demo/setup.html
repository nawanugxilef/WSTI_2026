Make your own Neo bot

5 small steps, about 2 minutes. Tick each one as you go. Your ticks are saved if you close this page.

  1. 1Open BotFather in Telegram

    BotFather is Telegram's official helper for making bots.

    Open BotFather ↗
    On a computer? Scan this with your phone camera.
    No Telegram yet? Get it free.
  2. 2Send /newbot

    Copy this and send it to BotFather. If you see a Start button first, tap it.

    /newbot
  3. 3Give it a name

    BotFather asks what to call your bot. Send this (or any name you like):

    My Neo
  4. 4Give it a username

    Now it asks for a username. I made a unique one for you:

    BotFather says it's taken? Totally normal.

  5. 5Copy your token

    BotFather's "Done!" message has a long line like 123456789:AAH…. That's your token.

    Tap and hold it, then Copy. Keep it private, like a password. Don't paste it on any website.

🎉

Your bot exists!

Now put Neo on your computer. Three small things:

  1. Get Docker Desktop (free, one time).
    Download Docker ↗
  2. Download Neo and unzip it.
    ⬇ Download Neo (ZIP)
  3. Open WSTI_2026-main → Neo-D LedgerCraft. Type powershell in the folder's address bar and press Enter. Run this, then paste your token when it asks:
    docker compose run --rm setup

Mac or Linux? Open a terminal in that folder instead. Full guide: Run it yourself.

💡 Good to know: Neo runs on that computer, so it answers while the computer is on.

Turned off or asleep? No stress: Telegram holds your receipts for up to 24 hours and Neo catches up when it's back. An old PC or laptop left on at home works great. Turn off sleep mode so it stays awake.

Computer restarted? Neo starts again by itself once Docker is running. In Docker Desktop, tick Start Docker Desktop when you sign in (Settings → General).
